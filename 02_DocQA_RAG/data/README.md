# Data

`source_md/` holds 76 Markdown documents about "Insurellm", a fictional insurance-tech
company: company pages, client contracts, employee profiles and product descriptions.

Provenance: the InsureLM dataset supplied with the Datheon Generative AI internship course.
The content is synthetic (no real people or companies), and the instructor permitted its
public use.

The vector store (`chroma/`) and the usage log (`telemetry.jsonl`) are generated and git-ignored.
